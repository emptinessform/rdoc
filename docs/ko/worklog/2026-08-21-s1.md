# 2026-08-21 (2) — S1: 읽기 전용 뷰어 제품화

로드맵 S1 범위: 렌더러 공백, 실문서 코퍼스 안정성, 줌, 텍스트 선택+복사.

## 구현

- **렌더러 공백**: `Paint::Linear/Radial` → `<linearGradient>/<radialGradient>`
  (userSpaceOnUse, stop-opacity), `Group.clip` → `<clipPath>`(clip-rule),
  `Effect::OuterShadow` → `<filter><feDropShadow>`, `Stroke`의
  cap/join/dasharray. `Paint::Tile`은 미디어 레지스트리가 없어 명시적 폴백
  유지 (경고 카운트).
- **코퍼스 러너** (`src/bin/corpus.rs`): corpus/*.docx 일괄
  파싱→조판→SVG+참조PNG, 파일별 catch_unwind로 패닉 격리, 결과 표 출력.
- **웹 뷰어**: 줌(75~200%, viewBox 기반), 마우스 드래그 선택(4px 임계,
  클릭=커서와 구분), 부분 런 하이라이트 rect, Ctrl+C 복사(문단 경계 \n,
  미매핑 세그먼트는 y 변화로 개행 추정), `__t.select/copy/setZoom` 테스트 훅.

## 검증 (게이트)

- **코퍼스: 14/14 무패닉** — docx-rs 픽스처(Word/LibreOffice 출처: 각주,
  머리글/꼬리글, 이미지 inline+anchored, 중첩 표, 번호매김, 변경추적,
  하이라이트/밑줄 등). 페이지·런·매핑·경고·시간 표는 corpus 실행 출력 참조.
  경고 0. 매핑 0인 파일(머리글, 표, 변경추적)은 provenance 한계와 일치.
- **시각 스팟체크**: image_inline_and_anchor SVG vs rdocx 참조 PNG — inline
  이미지·anchored 위치 일치 (docs/evidence/s1-corpus-images.png).
- **선택+복사 실측** (헤드리스 자동화):
  - 단일 문단 부분 선택 → "backend that converts every glyph to a vector " 정확.
  - **문단 걸친 선택**(스타일 문단 + 한국어 문단) → 복사 텍스트
    `"Styled runs: … large 16pt.\n한글 조판 테스트 — 서버 "` — 개행 정확.
  - 하이라이트 시각 확인: docs/evidence/s1-selection-zoom.png.
- **줌**: 150% 적용 시 svg width 700→1050px, 히트테스팅 좌표계(viewBox)
  불변으로 선택·커서 정상.
- **편집 회귀 없음**: 클릭→타이핑 29.8ms, 백스페이스 40.5ms.
