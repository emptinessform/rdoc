# 2026-08-23 — S42: 모바일 대응 v1 (M3 착수)

## 목표·범위

모바일 브라우저에서 데모 실사용 최소선 — 뷰포트 메타, 좁은 폭
레이아웃, 탭 캐럿+소프트 키보드. 터치 드래그 선택 등 제스처는 후속.

## 한 일

- `<meta name="viewport" width=device-width>` (핀치 줌 허용 —
  user-scalable 기본값 유지).
- `@media (max-width: 640px)`: 패딩 축소, **페이지 svg
  `max-width:100%`** — 화면 폭에 맞춰 축소되어도 히트 매핑이
  getScreenCTM 경유라 클릭 정확도 유지(핵심 설계), 썸네일은 본문을
  밀지 않고 오버레이, status는 줄바꿈 배치.
- ime 입력에 autocapitalize/autocorrect/spellcheck off — 모바일
  키보드 간섭 방지 (탭 시 imeEl focus는 기존 동작 → 소프트 키보드).
- 터치 탭은 브라우저의 mousedown/mouseup 합성으로 기존 경로 그대로
  동작; 터치 드래그는 네이티브 스크롤 유지(v1 의도).

## 검증 (실측)

- **실제 390×844 뷰포트**(browse viewport): 메뉴바 5메뉴 유지·툴바
  wrap·페이지 382px로 맞춤 축소, 축소 상태에서 좌표 탭 → 캐럿
  off 3 정확 + "모바일" 타이핑 성공, 썸네일 오버레이 스크린샷
  docs/evidence/s42-mobile-390px.png.
- 신규 mobile-test(배터리용 정적 가드 + 인라인 축소 클릭 정합 5단정)
  — 배터리는 데스크톱 뷰포트로 돌므로 실뷰포트 검증은 단계 세션에서
  수행(러너가 뷰포트를 전환하면 후속 스위트가 오염되기 때문).
- 전체 배터리 **43/43 그린** (데스크톱 무회귀).
