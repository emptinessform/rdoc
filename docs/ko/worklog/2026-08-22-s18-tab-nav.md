# 2026-08-22 — S18-1: 표 Tab 셀 탐색 (Word 동작)

## 목표·범위

표 안에서 Tab/Shift+Tab으로 셀 이동(대상 셀 내용 선택 — Word 동일),
**마지막 셀에서 Tab = 새 행 추가 후 진입**. JS 전용 (S16 `table_op`와
S10-2 `selectParaOffsets` 재활용 — 새 wasm/포크 코드 없음).

## 구현

- `tabCell(path, dir)`: 셀 경로에서 (표, 행, 열) 도출 → 다음 셀 / 다음
  행 첫 셀 / (마지막 셀이면) `table_op('r')` 후 새 행 진입. 역방향은
  이전 셀 / 이전 행 마지막 열(존재 프로브로 탐색), 첫 셀에서는 정지.
- 대상 셀에 내용이 있으면 전체 선택, 빈 셀이면 캐럿 off 0.
- 첫 실행에서 잡은 버그: Tab이 셀 내용을 선택하면 캐럿이 null이라 다음
  Tab이 죽었음 → 위치를 캐럿 또는 선택(sel.a의 런 경로)에서 도출하도록
  수정.
