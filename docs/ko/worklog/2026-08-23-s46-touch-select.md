# 2026-08-23 — S46: 터치 드래그 선택 (M3 마감)

## 목표·범위

모바일 관례의 텍스트 선택 — **롱프레스(500ms) = 단어 선택**, 그대로
드래그하면 선택 확장(이때만 스크롤 차단), 빠른 이동은 스크롤 유지.

## 한 일

- 더블클릭 단어 선택을 `selectWordAtClient`로 추출해 롱프레스와 공유.
- touchstart(500ms 타이머) → 발화 시 단어 선택 + 프레스 지점을
  선택 앵커로 하는 드래그 상태 진입(+진동 10ms, 지원 기기),
  touchmove: 선택 중이면 preventDefault(passive:false)로 스크롤 차단
  후 기존 extendDragTo 재사용, 미발화 상태에서 10px 이상 이동 시
  타이머 취소(스크롤 우선), touchend/cancel 정리, 롱프레스 중
  contextmenu 억제.
- 탭 캐럿은 브라우저의 합성 마우스 이벤트 경로 그대로 (무변경).

## 검증 (실측)

- 신규 touch-test 3단정 (TouchEvent 합성): 롱프레스 650ms 후 공백
  없는 단어 선택, touchmove로 선택 길이 증가, 80ms 내 40px 이동
  시 선택 미발동(스크롤 시나리오).
