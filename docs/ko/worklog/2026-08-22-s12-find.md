# 2026-08-22 — S12-1: 찾기 (Ctrl+F)

## 목표·범위

텍스트 검색: 검색바 UI, 문단 단위 대소문자 무시 검색(렌더된 모든
스토리), 매치 하이라이트, Enter/Shift+Enter 순회, Esc 닫기. JS 전용
(wasm/포크 변경 없음).

## 설계 선택

- **현재 매치 = 기존 selection**: Word처럼 타이핑하면 치환, Ctrl+C 복사
  동작 — 별도 "현재 매치" 상태를 만들지 않고 기존 인프라에 얹음. 나머지
  매치만 주황 오버레이(.findhl, 상한 500개 — 카운트/순회는 전체 유지).
- 검색 소스는 문단 텍스트(`paragraph_text_at`), 문단 목록은 히트 순서의
  유일 경로(= 문서 순서, 머리글/각주/미주 포함). 좌표는 `refForOffset`
  (S10-2에서 추출한 헬퍼 재사용).
- 오프셋 산술: `indexOf`(UTF-16) 매치 후 `chars(slice)`로 코드포인트
  오프셋 변환 — 캐럿/편집 오프셋 체계와 일치.
- 편집 후 `apply()`가 열려 있는 검색을 재실행(무효화 자동). 지연 드레인
  이 페이지 DOM을 교체하면 오버레이가 사라지므로 드레인 완료 시 재도장.
- find 입력은 자체 keydown(+stopPropagation), 문서 핸들러는
  `e.target === findq` 가드 — 편집 단축키와 격리.

## 검증 (실측)

- find-test.js 그린: Ctrl+F 열기, "문장" 2건 매치+오버레이, Enter 순회
  마다 선택 == 검색어(경로 이동 확인), Shift 역순회 랩, "GLYPHRUN" →
  "GlyphRun"(대소문자 무시, 표 셀), **매치 위 타이핑 = 치환 + 매치 목록
  자동 갱신 + undo 1회 복원**, "머리글" → 머리글 스토리 검색, Esc 닫기
  + 오버레이 소거.
- 63페이지 프로브: 검색 27~45ms(700·1400 매치), 오버레이 캡 500 동작,
  순회 55ms + 화면 밖 매치로 자동 스크롤, 선택 정확("quartz").
- 회귀 그린: ux2 / ux3 / shift / ime / cellsel / notesel.
- 증거: docs/evidence/s12-find.png — 검색바 "문장" 1/2, 현재 매치 파란
  선택 + 다른 매치 주황 오버레이, 상태줄 "찾기 1/2".

## 한계 (기록)

- 문단 경계를 넘는 검색어는 매치 안 됨 (문단 단위 검색 — Word도 단락
  나눔 문자를 넣지 않는 한 동일).
- toLowerCase가 길이를 바꾸는 희귀 문자(터키어 İ 등)는 오프셋이 어긋날
  수 있음 — 한글/영문 무관, 필요 시 후속.

# S12-2: 바꾸기 (Ctrl+H)

## 목표·범위

찾기 확장: 바꾸기 입력 + "바꾸기"(현재 매치) + "모두"(전체). Ctrl+H로
바꾸기 상자 포커스. 모두 바꾸기는 스토리 전체에 걸쳐 **undo 1회**.

## 구현

- wasm `replace_all(json_ranges, text)`: 매치들을 **역순 적용**해 같은
  문단 안의 앞쪽 오프셋을 보존, 마커를 덮는 매치는 S10-3의
  `remove_ranges_notes` 공유(노트째 삭제), 전체가 1 히스토리 엔트리.
- 검색을 **비중첩 매치**로 수정 (다음 스캔을 매치 끝에서 — Word 동일;
  "aaaa"에서 "aa"는 2건). replace-all 안전성의 전제이기도 함.
- 현재 매치 바꾸기 = 기존 `replaceSelWith` 재사용(현재 매치가 곧
  selection이므로) 후, 재검색된 목록에서 치환 지점 이후 첫 매치로 전진
  (문단 순서 인덱스 비교). 치환문이 검색어를 포함해도 전진 규칙 때문에
  무한 루프 없음.
- Ctrl+H 오픈, replq 자체 keydown(Enter=바꾸기, Esc=닫기) + 문서 핸들러
  가드, `__t.replaceWith/replaceAllWith` 훅.

## 검증 (실측)

- repl-test.js 그린: Ctrl+H 오픈+포커스, "문장"→"구절" 현재 매치 치환
  후 남은 매치로 자동 전진(d/5 불변 확인), undo 1회 복원. **"편집"→
  "수정" 모두 바꾸기: 머리글+각주+미주 3건 동시 치환, undo 한 번에 세
  스토리 전부 복원**. "aaaa"에서 "aa" 2건(비중첩), 모두 바꾸기
  "aa"→"b" 단일 패스(재매치 없음).
- 회귀 그린: find / cellsel / notesel / ime / roundtrip / shift.
