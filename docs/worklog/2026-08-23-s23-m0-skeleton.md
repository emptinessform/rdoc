# 2026-08-23 — S23-1: M0 제품 골격 (워크스페이스 개편)

## 배경 (방향 전환)

사용자 결정: "PoC는 충분, 본격 기능 구현으로" — 제품 방향은 **범용 웹
DOCX 에디터**, 첫 마일스톤은 **M0 제품 골격**. S23-1은 그 1단계로
PoC 시절의 디렉터리·이름 부채를 정리한다.

## 목표·범위

1. 워크스페이스화: 루트 `Cargo.toml` + `crates/rdoc-core` (구
   `rdocx-svg-poc` 개명, lib `rdoc_core`).
2. 웹 앱을 저장소 루트 `web/`으로 승격, `corpus/`도 루트로.
3. 빌드 명령·문서(CLAUDE.md, README, tests README) 현행화.

검증 기준: 네이티브 빌드+테스트 그린, wasm 빌드, 전체 브라우저 배터리
그린 (스위트 32종).

## 한 일

- `git mv rdocx-svg-poc crates/rdoc-core`, `git mv crates/rdoc-core/web web`
  (사전에 web/를 서빙 중이던 http.server와 browse 데몬이 디렉터리를
  잠가 Permission denied — 프로세스 종료 후 이동, 서버는 새 `web/`에서
  재기동).
- 패키지 개명 `rdoc-core` / `use rdoc_core::` 일괄 치환
  (main.rs, bin/bench.rs, bin/corpus.rs), corpus.rs는 대상 디렉터리를
  인자로 받도록 (`corpus/` 기본).
- 루트 `.gitignore` 재작성 (target/, out/, corpus/*.docx, web/pkg/,
  web/malgun.ttf 등), 구 크레이트의 upstream/ 문서는
  `docs/upstream/legacy/`로.
- `web/index.html` import → `./pkg/rdoc_core.js`, wasm 산출물 재생성
  (구 rdocx_svg_poc.* 제거).
- CLAUDE.md 빌드 명령, README(실행/구조/업스트림/로드맵),
  web/tests/README.md 현행화.

## 검증 (실측)

- 네이티브: `cargo run --release -p rdoc-core --bin poc` 그린 (out/
  재생성), lib 테스트 9/9 그린, unused_mut 경고 1건 수정.
- wasm: `wasm-pack build crates/rdoc-core --release --target web
  --out-dir ../../web/pkg -- --no-default-features` 그린 →
  web/pkg/rdoc_core.js.
- 브라우저 전체 배터리 (새 web/ 루트에서 서빙): **32/32 그린** —
  개편이 순수 이동/개명임을 확인.
