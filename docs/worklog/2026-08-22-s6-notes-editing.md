# 2026-08-22 — S6-3: 각주/미주 편집

S6 경로 편집 체계를 노트 스토리(`fn/{id}/{문단}`, `en/{id}/{문단}`)로
확장. 포크 `svg-poc-0.8` c894b80.

## 구현

- 포크: `with_footnote_paragraph_mut` — 각주는 Document의 **타입 필드**라
  재직렬화 없이 직접 변경(dirty 마킹). `with_endnote_paragraph_mut` —
  미주는 타입 필드가 없어 헤더처럼 파트 파스→수정→재직렬화. 읽기
  카운터파트 2종. 이로써 **F-X037 6개 스토리 전부 편집 커버** (본문/표
  셀/머리글/꼬리글/각주/미주).
- **기존 결함 발견·수정**: `build_layout_input`이 각주를 패키지 파트에서만
  읽어 **미저장 타입 필드 각주(add_footnote·편집 API 경유)가 레이아웃에
  안 보였음**. open 시 파트→타입 필드로 로드되므로 타입 필드가 권위 —
  비어 있지 않으면 타입 필드 우선으로 수정. (에디터의 라이브 각주 편집이
  드러낸 upstream quirk — 후속 보고 후보.)
- rdoc: `EditPath::Note` 변형 추가, 4개 디스패처 확장 (편집 코어는 공유
  그대로). JS 편집 게이트 제거(모든 스토리 허용; 비귀속 세그먼트는
  여전히 캐럿 거부). demo에 각주 달린 문장 추가.
