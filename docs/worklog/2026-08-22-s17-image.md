# 2026-08-22 — S17-1: 이미지 삽입

## 목표·범위

캐럿 위치 인라인 이미지 삽입 — 툴바 파일 선택 + 클립보드 이미지
붙여넣기. 본문 스토리(셀 포함 Document-story 경로)만; 이미지 선택/이동/
크기 조절은 후속 (undo로 제거 가능).

## 구현 (포크 6e035f4 + rdoc)

- 포크 `insert_image_at(children, off, data, name, max_width_pt)`:
  `oxml_media::probe`로 원본 크기(치수 불명이면 거부) → max_width로
  축소 스케일 → `embed_image`(미디어 파트+rel) → 노트 참조와 같은 런
  경계 분할로 Drawing 런 삽입.
- wasm `insert_image(path, off, bytes, name)` — 최대 폭 300pt, 1
  히스토리 엔트리. 실패 시 mutate 체크포인트 복원이 고아 미디어 파트도
  같이 되돌림.
- JS: 툴바 "이미지" 버튼(숨은 파일 입력) + paste 핸들러 확장(클립보드
  파일 중 image/*가 있으면 이미지 삽입, 아니면 기존 텍스트 경로).
  이미지는 텍스트 0자라 캐럿 오프셋 유지.
