# 2026-08-22 — S17-1: 이미지 삽입

## 목표·범위

캐럿 위치 인라인 이미지 삽입 — 툴바 파일 선택 + 클립보드 이미지
붙여넣기. 본문 스토리(셀 포함 Document-story 경로)만; 이미지 선택/이동/
크기 조절은 후속 (undo로 제거 가능).

## 구현 (포크 6e035f4 + rdoc)

- 포크 `insert_image_at(children, off, data, name, max_width_pt)`:
  `oxml_media::probe`로 원본 크기(치수 불명이면 거부) → max_width로
  축소 스케일 → `embed_image`(미디어 파트+rel) → 노트 참조와 같은 런
  경계 분할로 Drawing 런 삽입.
- wasm `insert_image(path, off, bytes, name)` — 최대 폭 300pt, 1
  히스토리 엔트리. 실패 시 mutate 체크포인트 복원이 고아 미디어 파트도
  같이 되돌림.
- JS: 툴바 "이미지" 버튼(숨은 파일 입력) + paste 핸들러 확장(클립보드
  파일 중 image/*가 있으면 이미지 삽입, 아니면 기존 텍스트 경로).
  이미지는 텍스트 0자라 캐럿 오프셋 유지.

# S17-3: 이미지 선택/삭제

## 구현 (포크 7db1563 + rdoc)

- 포크 `remove_inline_image(index)`: 본문 문단·(중첩)표 셀을 문서 순서로
  걸으며 k번째 Drawing 런 콘텐츠 제거 — SVG DOM의 `<image>` 순서와 같은
  키. 미디어 파트는 무해한 고아로 잔류(패키지 GC 범위 밖). 단위 테스트.
- wasm `remove_image(index)` — 1 히스토리 엔트리.
- JS: `<image>` 클릭 = 선택(파란 외곽선, 캐럿/선택 해제),
  Delete/Backspace = 삭제, Esc/다른 곳 클릭 = 해제. apply()가 DOM을
  갈면 참조 무효화. 발견한 버그: `clickAt` 직접 호출 경로(테스트·훅)가
  imageSel을 안 지워서 mousedown 핸들러 외에 clickAt에도 해제 추가.

## 검증 (실측)

- imgsel-test.js 그린(repo 스위트 추가): 실제 마우스 클릭으로 2번째
  이미지 선택(외곽선+캐럿 해제), Esc/텍스트 클릭 해제, Delete = 대상만
  삭제 + undo 복원, Backspace 동일, undo 전체 역행(이미지 0개).
- 회귀 그린: img / ux2 / shift / ime / cellsel.
- 포크 rev 7db1563 고정, 네이티브 릴리스 빌드 확인.
