# 2026-08-21 (3) — S2: 편집 MVP

로드맵 S2 범위: 선택 범위 삭제/치환, Enter 문단 분할, B/I/U 서식 토글,
undo/redo, IME 조합 입력.

## 포크 패치 추가 (rev dec7d54)

- `Document::paragraph_body_index(i)` — paragraphs() 인덱스 → 본문 콘텐츠
  인덱스 (insert_paragraph/remove_content에 필요; 콘텐츠 컨트롤 앞은 None).
- `Paragraph::split_run(index, at)` — 텍스트 전용 런을 문자 오프셋에서 분할,
  속성 복제. 기존 `CT_P::insert_unwrapped_run`(하이퍼링크/코멘트/북마크 스팬
  정렬 유지)을 활용 — 런 *제거* API는 스팬 정합성이 복잡해 회피하고, 삭제는
  런 텍스트 트리밍으로 구현 (빈 런 잔류는 기록된 부채).

## 구현 (rdocx-svg-poc)

- lib.rs: `delete_range_in_para`(런 경계 걸친 트리밍), `split_paragraph`
  (런 서식 + 문단 style/alignment/numbering 승계), `merge_paragraph_into_prev`,
  `delete_range`(문단 걸친 삭제: 꼬리/머리 트리밍 + 중간 문단 제거 + 병합),
  `toggle_format`(경계 split_run 후 Word 의미론 — 전부 켜져 있으면 끔).
- wasm: 스냅샷 undo/redo (docx bytes, cap 100; 실패한 mutation은 체크포인트
  롤백), `delete_selection`/`replace_range`/`split`/`merge`/`toggle`/`undo`/
  `redo`/`paragraph_texts`.
- web: 선택 상태 타이핑=치환·Backspace=범위 삭제, Enter, 문단 첫머리
  Backspace=병합, Ctrl+B/I/U(같은 문단 한정), Ctrl+Z/Y, **숨김 input의
  composition 이벤트로 IME 조합**(진행형 replace_range), `__t` 훅 확장.

## 검증 (게이트)

- **네이티브 단위 테스트 7/7 통과** — 삽입/삭제 원복, 런 경계 범위 삭제,
  분할/병합 상호 역연산, 문단 걸친 삭제, 볼드 토글(재토글=해제, 텍스트 불변),
  IME 커밋 시뮬레이션. **각 테스트가 to_bytes→from_bytes 왕복 후 텍스트
  일치를 assert** (rdocx 재파싱 검증).
- **브라우저 자동화** (헤드리스):
  - Enter: 한국어 문단 (3,3) 분할 → "한글 " / "조판 테스트 — …", 커서 (4,0).
  - 문단 첫머리 Backspace → 병합 원상 복구.
  - 드래그 선택 치환 → 'THAT ' 삽입 확인.
  - 볼드 토글 → "age" 볼드 시각 확인 (s2-editing-final.png).
  - **IME 시뮬레이션** ㅎ→하→한→한ㄱ→한그→한글 진행형 치환, 스텝당 24.4ms,
    제목 스타일(파란 헤딩) 유지된 채 "rdo한글cx…" 삽입.
  - **undo 전체 롤백 → 9개 문단 전부 원본 일치, redo 11회 전량 재적용.**
- 증거: docs/evidence/s2-editing-final.png.

## 한계/부채

- 실제 Windows IME(조합 중 대기 글자 표시)는 수동 검증 필요 — 시뮬레이션은
  composition 이벤트 경로만 검증함.
- 서식 토글은 같은 문단 선택만. 치환은 삭제+삽입 2회 mutation이라 undo가
  2단계로 갈림. IME 조합도 스텝마다 스냅샷 (undo 노이즈).
- 빈 런 잔류 (런 제거 API 부재), 콘텐츠 컨트롤 포함 문서는 분할/병합 불가.
- Delete 키(앞으로 삭제), Home/End/상하 화살표 미구현.
