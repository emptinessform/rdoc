# 2026-08-22 — S19-1: 글자 색 (툴바 색상 선택)

## 목표·범위

서식 팔레트의 남은 소품: 선택 구간 글자 색. 포크 변경 없음
(`Run::set_color` 재사용, 크기와 동일 패턴).

## 구현

- lib.rs `set_color_in`(런 경계 분할 + 커버 런 set_color; 6자리 hex
  검증) / `set_color_at`(관문 경유). wasm `set_color_ranges`(문단별
  구간, 1 undo).
- JS: 툴바 `<input type="color">` → `selectionRanges()` 정규화 적용.
  색은 리플로우가 없어(글리프 지오메트리 동일) **선택 refs가 유효 —
  선택 유지·복원** (크기 변경과의 의도적 차이).

## 검증 (실측)

- color-test.js 그린(repo 스위트 추가): 4자 선택 CC0000 → 해당 글리프
  그룹 fill rgb(204,0,0), 밖 rgb(0,0,0) 불변, **선택 유지**, undo 1회
  원색 복원, 008800이 .docx 저장→재로드 후 유지.
- 회귀 그린: fontsize / biu / shift / ime.
- 첫 실행 실패 1건은 테스트 자체의 무의미한 중복 체크(제거).
