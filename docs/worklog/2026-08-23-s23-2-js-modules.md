# 2026-08-23 — S23-2: web/index.html ES 모듈 분할 (M0)

## 목표·범위

index.html의 단일 인라인 스크립트(~1,580줄 JS)를 ES 모듈로 분할해
이후 기능 작업(M1)의 변경 단위를 좁힌다. **순수 코드 이동 + 상태 접근
명시화만** — 동작 변경 없음, `window.__t` 훅 전부 유지.

검증 기준: 전체 브라우저 배터리 32/32 그린 + 스모크(부팅/데모/타이핑).

## 설계

- 공유 가변 상태(caret, sel, pageHits, zoom, imageSel, comp,
  selAnchor/Focus, lastCopied, lastMs/Delta, conv)를 `js/state.js`의
  단일 객체 `S`로 승격 — 모듈 간 변이가 `S.` 접두사로 전부 드러남.
  import 바인딩 재할당 금지(ES 모듈 제약)도 자연 해소.
- 모듈 경계는 기존 섹션 주석을 따름 (10개, web/js/):
  - `state.js` — S + 순수 헬퍼 (chars/width/cum/cmpPos/orderSel/
    siblingPath/sameContainer/storyOf)
  - `render.js` — apply 델타, 지연 페이지 드레인, 줌, 썸네일, status
  - `view.js` — 히트테스트, 오프셋↔좌표, 캐럿/선택/프리에딧 오버레이,
    selectedText, 줄 이동 기하(lineEdgeOff/lineTarget)
  - `edit.js` — edit() 트랜잭션, selRange/selectionRanges, 타이핑·
    분할·병합·삭제·노트·undo
  - `format.js` — 정렬·크기·색·스타일·표 구조·Tab 셀 탐색
  - `clipboard.js` — 복사/잘라내기/붙여넣기, 인라인 이미지
  - `find.js` — 찾기/바꾸기 (find 상태는 모듈 내부에 유지, 접근자 export)
  - `ime.js` — IME 조합, `input.js` — 마우스/키보드, `main.js` — 부트
    스트랩 + `__t` 조립
- 순환 import(render↔view↔find↔edit)는 호출이 전부 런타임(이벤트
  이후)이라 안전 — 모듈 톱레벨은 DOM 참조 const와 함수 선언뿐.
- 원본이 `await init()` 뒤에 리스너를 달던 순서를 보존하기 위해 배선은
  각 모듈의 `wire*()`로 분리, main.js가 wasm init 후 호출 (준비 전
  클릭이 conv 미존재로 죽는 창 없음 — 원본과 동일).
- 부수 정리: 페이지 타이틀/헤더의 "PoC" 표기 제거 ("rdoc editor").

## 한계·메모

- 모듈 파일은 index.html의 `?v=` 캐시 버스트를 물려받지 않음 — 개발 중
  JS 수정 후엔 브라우저 캐시 주의 (http.server는 Last-Modified 재검증
  이라 실사용 문제는 없음).
- find 내부 상태(findMatches/findCur)와 mouse 상태는 각 모듈 로컬로
  남김 — 밖에서 쓰는 곳이 접근자뿐이라 S로 올릴 이유 없음.
- M0 잔여: S23-3 테스트 러너 스크립트화.
