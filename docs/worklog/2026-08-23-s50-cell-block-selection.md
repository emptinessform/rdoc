# 2026-08-23 — S50: 셀 블록 선택 + 병합 연동 (사용자 피드백)

## 목표·범위

"셀을 선택하여 병합" — Word/LibreOffice의 가장 익숙한 방식인 **셀 안에서
드래그해 다른 셀로 넘어가면 셀 단위 블록 선택으로 전환**(셀 전체
하이라이트)을 구현하고, 그 상태에서 병합이 동작하게 한다. (한/글 F5의
'셀 블록'과 같은 결과를 드래그로.) v1는 가로(한 행) 병합 — 세로(vMerge)
병합 편집은 코어 확장이 필요해 후속.

## 한 일 (코어 변경 없음 — 웹 전용)

- **tablegeo.ts 신설**: 표 렌더 기하 공용 모듈 — 열 경계 x(colX),
  행 밴드 y(rowY, 히트 y±글자 크기 기반 추정 후 인접 행과 중간점에서
  맞닿게 보정), 점→셀 매핑 `cellAt(page,x,y)`. colresize.ts의 중복
  기하 코드를 이 모듈로 대체(동작 동일, 코드 −50줄).
- **cellsel.ts 신설**: 셀 블록 상태 {page, table, r0,c0,r1,c1} +
  반투명 오버레이(.cellselrect, 셀 전체 rect). set/clear/draw.
- **input.ts**: extendDragTo에서 앵커가 셀 안이고 포인터가 같은 표의
  다른 셀에 들어오면 텍스트 선택 대신 셀 블록으로 전환(직사각 영역).
  앵커 셀로 되돌아오면 텍스트 선택 복귀. Esc/클릭/새 mousedown에서
  해제. apply()(재레이아웃)에서도 해제(기하 무효).
- **format.ts mergeCells**: 셀 블록 우선 소비 — 1행×N열이면 각 셀의
  첫 문단 경로로 기존 merge_cells 호출(1 undo), 다중 행이면
  "세로 병합 미지원" 안내 후 블록 유지. 기존 텍스트 scatter 선택
  경로도 그대로 동작.
- __t 훅: cellSel / selectCells / clearCellSel.

## 검증 (실측)

- 신규 cellsel-test 12단정: (0,0)→(0,1) 실제 마우스 이벤트 드래그로
  1×2 블록 진입(오버레이 2개, 텍스트 선택은 꺼짐), 병합 버튼 →
  행 0이 3셀→2셀(d/10.0.2.0 소멸)·캐럿 d/10.0.0.0·undo 복원,
  selectCells 3셀 오버레이 3개 + Esc 해제, 다중 행 블록 병합 거부
  (구조 불변), clickAt 해제.
- 전체 배터리 **46/46 그린** (colresize 기하 공용화 후 tblresize 포함
  무회귀).

## 한계·후속

- 셀 블록은 단일 페이지·단일 표. gridSpan(이미 병합된 셀)이 있는 행은
  경로 열 인덱스와 그리드 열이 어긋날 수 있음 — cellAt은 그리드 기준,
  병합 경로는 셀 인덱스 기준이라 스팬 행에서 재병합은 어긋날 수 있다
  (거부되거나 다른 셀 병합). 후속: wasm에 셀 rect 직접 노출.
- 세로(vMerge) 병합, F5식 키보드 셀 블록 확장은 후속.
