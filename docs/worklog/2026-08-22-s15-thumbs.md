# 2026-08-22 — S15-2: 페이지 썸네일 패널

## 목표·범위

좌측 사이드바에 페이지 미니어처 + 클릭 이동. JS 전용 (wasm 변경 없음 —
페이지 SVG는 DOM에 이미 있는 것을 재활용).

## 구현

- 토글 버튼(🗂) → 고정 사이드바(#thumbs). 썸네일 = 페이지 SVG DOM의
  outerHTML을 Blob URL로 만든 `<img>` — wasm 재렌더 없음, blob 교체
  시 이전 URL revoke.
- 갱신 경로: `applyPage`(즉시/드레인 공통)가 해당 인덱스를 thumbDirty에
  마킹 → 60ms 타이머 + 12ms 슬라이스로 소진. dirtyPages에 아직 지연 중인
  페이지는 blob을 미뤄 스테일 썸네일 방지. 페이지 수 변화는 apply에서
  `syncThumbCount`.
- 클릭 → 해당 페이지 scrollIntoView. 페이지 번호 라벨.

## 사고 기록 (프로세스 개선)

패치 스크립트의 `open(p, "w").write(s)`가 이모지 서로게이트 인코딩
에러로 **쓰기 전 truncate만 수행하고 죽어 index.html이 0바이트**가 됐다.
직전 커밋에서 즉시 복구(유실 없음 — 단계 단위 커밋 규율이 안전망).
재발 방지: 패치 스크립트는 `s.encode()`를 open 전에 수행하는 바이너리
쓰기 패턴으로 변경.

  src 보유, 편집 후 해당 썸네일 재생성 소진, Enter 30회로 페이지가 늘면

- 63페이지 프로브: 열기 후 전체 썸네일 4.6s (12ms 슬라이스 idle 생성,
