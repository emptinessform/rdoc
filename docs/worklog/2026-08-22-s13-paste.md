# 2026-08-22 — S13-1: 붙여넣기 (Ctrl+V)

## 목표·범위

플레인 텍스트 붙여넣기. 복사(Ctrl+C)만 있고 붙여넣기가 없던 공백 해소.
개행 포함 텍스트는 Enter로 타이핑한 것과 같은 문단 구조가 되어야 하고,
전체가 undo 1회. 포크 변경 없음.

## 구현

- lib.rs: wasm `split()`의 스토리별 분기를 `split_at(doc, at, off)`
  디스패처로 승격 (merge_at과 대칭, wasm은 위임). EditPath에 Clone 파생.
- wasm `paste_text(path, off, text)`: 개행 정규화(\r\n·\r→\n) 후 줄
  단위로 insert → split → 다음 형제로 이동을 **한 mutate**에서 반복 —
  원자적(중간 실패 시 S10-1의 체크포인트 복원), 1 히스토리 엔트리.
- JS: document paste 리스너(찾기/바꾸기 입력은 제외)에서 text/plain
  추출. 선택이 있으면 단일 라인 = 기존 `replaceSelWith`(원자적 치환),
  멀티라인 = deleteSel 후 paste(2 엔트리 — 한계로 기록). 캐럿은 마지막
  줄 끝(경로 = 원 경로 + 줄 수 - 1).

## 검증 (실측)

- paste-test.js 그린: 단일 라인 삽입+캐럿+undo 1회, **3줄 붙여넣기 =
  머리("…각하나")/"둘"/꼬리("셋주가…") 문단 3개 정확 + 캐럿 마지막 줄
  끝 + undo 한 번에 구조 복원**, 선택 위 단일 라인 = 원자 치환, 각주
  안 멀티라인 붙여넣기(노트 스토리 split 경로)+복원.
- 회귀 그린: find / repl / cellsel / ime / split / roundtrip.

## 한계 (기록)

- 플레인 텍스트만 (서식 있는 클립보드는 text/plain으로 강등).
- 멀티라인을 선택 위에 붙여넣으면 undo 2회 (삭제 1 + 붙여넣기 1).

# S13-2: 잘라내기 (Ctrl+X)

## 구현

복사 + 선택 삭제의 합성 — `cutSelection() { copySelection(); deleteSel(); }`
(JS 10줄). 클립보드 기록은 삭제 전에 동기 캡처, 문서 변경은 deleteSel의
기존 모양(같은 문단/형제/셀 간 scatter/마커 동반 삭제) 그대로 1 undo.

## 검증 (실측)

- cut-test.js 그린: 같은 문단 4자 잘라내기 = 버퍼 정확·텍스트 소거·캐럿
  유지·undo 1회, 문단 간 잘라내기 = 병합+각주 동반 삭제+undo 복원,
  **잘라내기→끝으로 이동→붙여넣기 = 텍스트 이동, undo 2회 복원**.
- 회귀 그린: ux2(복사) / paste / notesel.
- 참고: 문단 간 복사 텍스트에 각주 마커 글리프("2")가 줄로 포함되는
  것은 기존 selectedText 동작(장식 런 포함) — 붙여넣기 시 별도 문단이
  되므로 후속 개선 후보.
