# 2026-08-22 — S3-②③④: 델타 렌더링 + 지속 엔진 + 문단 블록 캐시

승인된 순서(④→②)대로 진행. 기준선: 63페이지, 키 입력당 네이티브 1,144ms /
wasm ~590ms. 게이트 <30ms.

## ④ 델타 렌더링 (rdocx-svg-poc, 커밋 "S3-2")

- 히트맵 수집을 SVG 생성에서 분리 (`collect_hits` — 텍스트 워크만).
- 페이지 구조 해시를 SVG 생성 **전에** 계산 → 변경 페이지만 SVG 생성·전송·
  DOM 교체. per-page defs + `pg{N}-` 접두사로 DOM id 충돌 제거,
  HitRun id 페이지-로컬화, JS 선택 모델 (page, idx) 재작성.
- wasm 델타 JSON: `{total, pages:[[i,svg]], hits:[[i,runs]]}` —
  문단 인덱스만 밀리는 편집(Enter)을 위해 SVG/히트 해시 분리.
- 실측: wasm ~590 → 323~410ms, "1/63 pages redrawn".

## ② 지속 레이아웃 세션 (포크 rev 6a0b151)

계측(RDOCX_TIMING) 결과 → 순차 공략:
- `build_input` 1~3ms, `engine.layout` ~150ms (blocks ~100 / paginate ~19 / 기타 ~45).
- **FontManager.shape_memo**: (font id, text+size 해시)→ShapedText 메모.
- **Engine 재사용**: 추가 폰트 지문 가드(재로딩 방지), `rdocx::Document`가
  엔진을 보유해 편집을 넘어 캐시 생존 (wasm의 13MB 주입 폰트 복사 제거).
- **문단 블록 캐시**: 문단 XML+폭+revision view+폰트셋 지문 → ParagraphBlock.
  **마커(번호/불릿) 있는 문단은 캐시 제외**로 NumberingState 정합 보존.
  blocks 100→32ms (잔여는 Debug 포맷 지문 비용 + 번호 문단 + 표).
- 함정: 계측용 `Instant::now()`가 wasm32에서 패닉 → cfg 게이트.

## 결과 (63페이지 키 입력당)

| 경로 | 이전 | 이후 | 배율 |
|---|---|---|---|
| 네이티브 재조판 | 1,144ms | **101ms** | 11.3× |

## 남은 것 (게이트 <30ms까지)

- 네이티브 잔여 101ms 구성: 블록 32(지문 비용 포함) + 페이지네이션 15 +
  엔진 후처리(머리글/각주/필드/결과 조립) ~45 + 히트 수집/매핑.
- 후보: 지문을 Debug 포맷 대신 전용 워커로 (~20ms 절감 추정), 재시작 가능한
  페이지네이션, 머리글/꼬리글 캐시, 히트 수집 증분화.
- ~~undo/redo는 Document 재생성이라 엔진 캐시가 식음 (55ms/키로 일시 상승)~~
  → 아래 "undo/redo 엔진 이월"로 해결.
- 블록 캐시의 알려진 한계: 스타일 *정의* 변경은 지문에 안 잡힘 (문서화됨;
  현 에디터는 스타일 정의를 편집하지 않음).

## undo/redo 엔진 이월 (S3-4, 포크 rev bd26eda)

"undo/redo는 Document 재생성이라 엔진 캐시가 식음" 항목 해결:

- 포크에 `Document::take_layout_engine()` / `set_layout_engine()` 공개
  (crates/rdocx/src/document.rs:616,624, svg-poc 브랜치 bd26eda — 푸시 완료).
- wasm.rs `replace_doc()`: undo/redo에서 복원된 Document로 교체할 때 기존
  엔진(shape_memo + 문단 블록 캐시 포함)을 새 Document로 이월.

실측 (63페이지 bench.docx, 헤드리스 브라우저, 콜드 로드 후 각 3회):

| 조작 | 이월 전 | 이월 후 |
|---|---|---|
| 타이핑 | 126~152ms | 64~103ms |
| undo | 150~266ms | 75~91ms |
| redo | 217~302ms | 82~126ms |

undo/redo가 타이핑과 같은 수준으로 수렴 (이전엔 ~2배). 델타 렌더링은
"1/63 pages redrawn" 유지. 검증: 네이티브 테스트 7/7, 코퍼스 14/14,
wasm 빌드·에디터 루프(타이핑/undo/redo) 정상.
