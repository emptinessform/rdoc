# 2026-08-22 — S7-1: Enter/병합의 전 스토리 확장

Enter(문단 분할)와 Backspace 병합을 본문 전용에서 **표 셀·머리글·꼬리글·
각주**로 확장. 포크 `svg-poc-0.8` 3d19432.

## 구현

- 포크 코어 `split_simple_paragraph(p, off) -> CT_P`: 연결 런 텍스트의
  문자 오프셋에서 분할, 경계 런은 서식 복제로 양분. **원래 문단 마크
  (sectPr 포함)는 꼬리로 이동, 머리는 sectPr 없는 사본** — Word의 Enter
  의미론. 경계 프로젝션(하이퍼링크/코멘트/북마크/컨트롤/리비전) 있는
  문단은 거부 (런 앵커 재매핑 필요 — 백로그).
  `merge_simple_paragraphs`는 형제 런 이어붙이기 (같은 plain 조건).
- 스토리별 배선: Document 경로(본문+중첩 표 셀 — `table_cell_slot_mut`
  워커), 머리글/꼬리글(파트 통째 파스→수정→재직렬화 공용 헬퍼), 각주
  (타입 필드). **미주 분할/병합은 타입 필드 승격 후로 유보**.
- 본문 Enter/병합도 이 경로로 **통일** — 이제 분할 후 캐럿은 모든
  스토리에서 "마지막 경로 세그먼트 +1" (`siblingPath`), 병합은 "같은
  컨테이너의 직전 형제가 문단일 때"만. (본문 병합이 이전의 order 기반
  "표 건너뛰고 병합"에서 "직전 형제가 표면 거부"로 바뀜 — Word 동작에
  더 가깝고 예측 가능.)
- `__t.backspace` 훅이 실제 키 동작(off 0 → 병합)과 일치하도록 수정
  (테스트 중 발견 — 훅과 keydown 경로가 달랐음).

## 검증 (헤드리스, 6조 전부 통과)

- 셀/머리글/각주/본문 각각: Enter → head/tail 텍스트 정확 분할 + 캐럿
  tail·off 0 → Backspace 병합 원복 + 캐럿 head 끝 → undo 2회 원복.
- 컨테이너 첫 문단 병합 조용한 거부 (문서 무손상).
- 머리글 분할이 저장 왕복(save→reload) 후에도 유지.
- 회귀: 셀(Enter 단언 갱신)/HF/IME/왕복 스위트 그린. 네이티브 27ms
  (min 23), 테스트 7/7, 코퍼스 14/14.

## S7-2: 각주 추가/삭제 (포크 8ccd383)

- 포크 `insert_footnote_ref_at`(경로+오프셋에 참조 런 삽입 — 중간 런은
  split_run으로 경계 생성; 빈 노트 생성; 표 셀 포함) +
  `remove_footnote`(노트 + 본문/중첩 셀의 모든 참조 런 제거).
- UI: **Ctrl+Alt+F** 삽입(캐럿이 새 노트 `fn/{id}/0`으로 이동, Word처럼),
  **Ctrl+Alt+D** 삭제(노트 안에 캐럿). 각 1 undo 엔트리 (mutate 1회).
- 검증 (6조 전부 통과): 삽입 시 본문 텍스트 불변+마커/노트 히트 증가,
  새 노트 타이핑, **저장 왕복 후 유지**, 삭제 시 노트·마커 동시 소멸,
  undo 1회로 복원 + redo, 기존 각주 무손상. 분할/IME 회귀 그린.
  네이티브 테스트 7/7, 코퍼스 14/14.
- UX 노트: 빈 노트는 글리프가 없어 첫 글자 입력 전까지 캐럿이 안 보임
  (상태바에는 표시) — 개선 후보.

## S7-3: 빈 문단 캐럿/클릭 가시성 (포크 d0bc41d)

- 문제: 빈 문단은 렌더 요소가 없어 히트도 없음 — 끝-분할의 빈 꼬리,
  빈 표 셀, 새 각주가 전부 클릭 불가·캐럿 불가 dead zone.
- 수정 (포크 레이아웃): 빈 문단의 유일한 빈 줄에 **폭 0 빈 텍스트
  세그먼트**를 주입 — 해석된 기본 폰트(캐럿 높이 정확) + 소스 스팬
  0..0. provenance 유무와 무관하게 생성해 ordinary/provenance 레이아웃
  구조 동일성 유지 (compat 테스트 통과). JS findHit의 zero-adv 제외
  해제.
- 검증 (전부 통과): 끝-분할 빈 꼬리 — 즉시 캐럿, 이탈 후 재클릭 가능,
  타이핑; 새 빈 각주 — 캐럿 즉시 표시 + 타이핑 (S7-2의 UX 노트 해소).
  분할/노트/IME/왕복 회귀 그린, rdocx-layout 147/147, 테스트 7/7,
  코퍼스 14/14, 네이티브 31ms.
