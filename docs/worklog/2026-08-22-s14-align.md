# 2026-08-22 — S14-1: 문단 정렬 (Ctrl+L/E/R + 툴바)

## 목표·범위

서식 확장 1단계: 문단 정렬(왼쪽/가운데/오른쪽 — Word 단축키 Ctrl+L/E/R)
+ 툴바 버튼 3개. 캐럿 문단 또는 선택이 걸친 모든 문단, 1 undo. 포크
변경 없음(기존 `Paragraph::set_alignment` 재사용).

## 구현

- lib.rs: `with_paragraph_at(doc, at, f)` — 6개 스토리 공용 문단 핸들
  디스패처(향후 서식 연산의 공용 기반), `set_alignment_at(at, 'l|c|r|j')`.
- wasm `set_alignment_paths(json_paths, align)`: 경로 배열 일괄 적용,
  1 히스토리 엔트리.
- JS `alignSelection(align)`: 캐럿 문단 / same·siblings 선택의 구간
  문단들 / scatter 선택의 touched 문단들 수집. 텍스트 불변이므로 캐럿
  보존, 선택은 refs로 복원. 툴바 ⮜⬌⮞ + Ctrl+L/E/R.

## 검증 (실측)

- align-test.js 그린: Ctrl+E로 첫 줄 x 72→219.6(가운데), Ctrl+R 추가
  우측, Ctrl+L 원위치(±0.5), undo 3회 역행. **두 문단 걸친 선택 정렬 =
  1 엔트리(undo 1회에 둘 다 복원)**. 표 셀 문단 오른쪽 정렬 + .docx
  저장→재로드 후 유지.
- 회귀 그린: shift / cellsel / find / paste / cut / ime.

# S14-2: 폰트 크기 (툴바 pt 입력)

## 구현

- lib.rs `set_size_in`: toggle_in과 같은 런 경계 분할 후 커버 런에
  `Run::set_size(pt)` (1.0~1638pt 가드), `set_size_at` =
  `with_paragraph_at` 관문 경유 — 6개 스토리 공짜.
- wasm `set_size_ranges(json, pt)`: 문단별 구간 배열 일괄, 1 히스토리
  엔트리.
- JS `selectionRanges()`: 임의 선택(same/siblings/scatter)을 문단별
  {path,start,end}로 정규화하는 공용 헬퍼(scatter는 기존 분해 재사용).
  크기 변경은 리플로우로 선택 refs가 낡으므로 **캐럿을 구간 시작으로
  수렴**(정렬과 달리 선택 미복원 — 의도). 툴바 숫자 입력(6~96pt),
  입력창 키는 편집기로 전파 차단.

## 검증 (실측)

- fontsize-test.js 그린: 4자 선택 24pt → **정확히 그 구간만 24, 밖은
  base(11) 유지**(히트 size를 문자 단위로 전수 검사), undo 1회 복원.
  두 문단 걸친 선택 18pt = 1 엔트리(undo 1회에 양쪽 복원). 30pt가
  .docx 저장→재로드 후 유지.
- 회귀 그린: align / cellsel / ime / shift / roundtrip.

# S14-3: B/I/U 임의 선택 확장

## 목표·범위

Ctrl+B/I/U의 "같은 문단 선택만" 제한 제거 — 형제 문단·셀 간 scatter
선택까지, Word의 전역 토글 의미론(선택 전체가 켜져 있으면 끄고,
혼합이면 모두 켬)으로.

## 구현

- lib.rs: `format_all_on_in`(비변경 읽기 — 겹치는 런 전수 검사) +
  `set_format_in`(토글 아닌 명시 설정; toggle_in과 같은 경계 분할),
  각각 `with_paragraph_at` 관문 경유 `format_all_on_at`/`set_format_at`.
- wasm `toggle_ranges(json, fmt)`: 1패스 전역 all_on 판정 → 2패스
  `!all_on` 설정, 1 히스토리 엔트리. 읽기 전용 `ranges_format_on`
  (테스트·향후 툴바 버튼 상태용).
- JS `toggleFmt`: selRange 제한 분기 삭제, `selectionRanges()` 정규화로
  일원화. `__t.fmtOn`/`selRanges` 훅.

## 검증 (실측)

- biu-test.js 그린: 같은 문단 경로 정상(fmtOn 왕복), **두 문단 선택
  볼드 = 1 엔트리(undo 1회에 양쪽 해제)**, all-on 재토글 = 전체 해제,
  **혼합 상태(한쪽만 볼드) 토글 = 전체 설정(Word 규칙)**, 셀 간 scatter
  이탤릭 + undo.
- 회귀 그린: roundtrip / ux2 / cellsel / fontsize / ime.

서식 3종(B/I/U·정렬·크기)이 모두 임의 선택 모양에서 동작 — S14 마감.
