# 2026-08-22 — S16-1: 표 구조 편집 (행·열 추가/삭제)

## 목표·범위

캐럿이 있는 셀 기준의 표 구조 편집: 아래에 행 추가 / 행 삭제 / 오른쪽에
열 추가 / 열 삭제. 툴바 버튼 4개(행+ 행− 열+ 열−). 최상위 표만(중첩
표 셀은 거부). 구조 연산이므로 페이지네이션 풀패스 폴백.

## 구현 (포크 f0362c6 + rdoc)

- 포크: `table_insert_row`(참조 행 클론 — 셀 속성 유지·내용은 빈 문단
  1개, Word의 "아래 삽입" 서식 상속), `table_delete_row`(마지막 행
  거부), `table_insert_column`(행별 참조 셀 클론 + tblGrid 폭 복제,
  ragged 표 거부), `table_delete_column`(어느 행이든 마지막 셀이면
  거부). 공통 관문 `plain_table_mut`: 비모델 raw XML·콘텐츠 컨트롤을
  가진 표는 보수적 거부(행/셀 삽입이 태그된 write-back 인덱스를
  흔들기 때문). 단위 테스트 1종.
- wasm `table_op(path, 'r'|'R'|'c'|'C')`: 셀 경로(d/T.r.c.p, 정확히 4
  세그먼트)에서 표/행/열 도출, 1 히스토리 엔트리.
- JS: 툴바 4버튼, 삭제 연산 후 캐럿 해제(경로 무효), 삽입은 캐럿 유지.

## 검증 (실측)

- 포크 단위 테스트: 클론/시프트/grid 동기/마지막 행·열 거부.
- tblops-test.js 그린(repo 스위트 추가): 데모 표(4×3)에서 행 삽입 →
  빈 행 + 아래 행 시프트 + 캐럿 유지 + undo, 행 삭제 + undo, 열 삽입 →
  머리행 포함 전 행에 빈 셀 + 시프트 + undo, 열 삭제 + undo, **새 행에
  타이핑 후 .docx 저장→재로드 = 구조·텍스트 유지**, 본문 캐럿에서 거부
  (문서 불변).
- 회귀 그린: cell / cellsel / split / roundtrip / biu / ime.
- 포크 rev f0362c6 고정, 네이티브 릴리스 빌드 확인.

## 한계 (기록)

- 열 삽입은 참조 열의 폭을 복제 — 표 전체 폭이 늘어난다 (Word는
  재분배). 후속 후보.
- 중첩 표, gridSpan 병합 셀이 있는 표는 열 연산 결과가 어긋날 수 있어
